1. Match the plan to real question volume

Use recent support or sales questions to estimate demand. A credit allowance is not the same thing as a guaranteed number of full conversations, because one conversation can use several answers.

2. Count every domain and source

List the websites, subdomains, PDFs, documents, and connected knowledge sources you actually need. Confirm the plan covers the source boundary rather than paying for capacity you will not use.

3. Test the refusal behavior

Ask one question that is clearly documented and one that is not. A useful assistant should ground answers in approved material and make uncertainty visible instead of improvising policy or pricing.

4. Budget maintenance, not just setup

Set a recurring review for prices, policies, availability, and stale pages. The cheapest plan is not cheap if nobody owns source updates or checks the answers visitors receive.

5. Confirm the exit path

Before paying, identify the account owner, cancellation controls, data access, source export, renewal date, and what happens to the widget if the subscription ends.
